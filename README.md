# Finance Transaction & Risk Analysis | Power BI

## Project Overview

**Finance Transaction & Risk Analysis** is an interactive Power BI dashboard designed to analyze financial transactions, customer activity, transaction behavior, and potential risk indicators.

The dashboard provides a consolidated view of transaction activity and enables users to explore financial performance across key transaction attributes such as **transaction amount, transaction status, transaction type, merchant category, fees, taxes, accounts, and transaction dates**.

The project focuses on transforming transactional data into an interactive business intelligence solution for monitoring financial activity and identifying meaningful patterns.

---

## Business Objective

The primary objective of this project is to provide a clear and interactive view of financial transaction activity and support data-driven analysis.

The dashboard is designed to help answer questions such as:

* What is the overall transaction activity?
* How are transaction amounts distributed over time?
* Which transaction types are most common?
* What are the different transaction statuses?
* Which merchant categories generate significant transaction activity?
* How much is being generated through fees and taxes?
* Which accounts contribute to transaction activity?
* What transaction patterns may require further investigation?

---

## Dataset

The dashboard is built around a `finance_transactions` dataset containing transaction-level financial information.

### Key Attributes

* `transaction_id`
* `reference_no`
* `account_id`
* `transaction_date`
* `transaction_type`
* `transaction_status`
* `merchant_category`
* `amount`
* `fee_amount`
* `tax_amount`

These attributes provide the foundation for analyzing transaction activity, financial amounts, account behavior, and potential risk indicators.

## Dashboard Structure

The Power BI report contains two main analytical pages:

### 1. Overview Analysis

Provides a high-level view of financial transaction activity.

The overview is designed to give users a quick understanding of the overall transaction environment and important financial indicators.

### 2. Transactions

Provides a more detailed view of individual transaction activity.

The page focuses on transaction-level attributes such as:

* Transaction date
* Transaction type
* Transaction status
* Merchant category
* Account
* Transaction amount
* Fees
* Taxes

## Analytical Areas

### Transaction Analysis

Transactions can be analyzed based on:

* Transaction type
* Transaction status
* Transaction date
* Transaction amount
* Account
* Merchant category

This helps identify transaction patterns and changes in financial activity.

### Financial Analysis

The dashboard incorporates financial measures including:

* Transaction Amount
* Fee Amount
* Tax Amount

These measures provide insight into the financial value associated with transaction activity.

### Merchant Category Analysis

Merchant categories can be analyzed to understand where transaction activity is concentrated and which categories contribute significantly to the overall transaction volume or value.

### Account Analysis

Account-level analysis helps identify transaction activity across different accounts and provides another dimension for understanding customer and transaction behavior.

### Transaction Status Analysis

Transaction status can be used to distinguish different transaction outcomes and identify patterns that may require additional investigation.

## How to Use the Dashboard

1. Download or clone the repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Refresh the data if required.
4. Navigate between the **Overview Analysis** and **Transactions** pages.
5. Use available filters and interactive visuals to explore transaction activity.
6. Analyze financial and transaction patterns across different dimensions.
